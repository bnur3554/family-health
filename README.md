# Семейное здоровье (Family Health)

Мобильное веб-приложение (PWA) для всей семьи: контроль приёма витаминов, хранение и интерпретация медицинских анализов, планирование питания и покупок с учётом индивидуальных дефицитов каждого члена семьи.

## Демо

Откройте приложение: **[family-health.html](family-health.html)** — или разверните через GitHub Pages (см. ниже).

## Возможности

- 👨‍👩‍👧‍👦 **Профили семьи** — имя, роль, возраст, пол, аватар
- 💊 **Витамины** — расписание с несколькими времённами приёма и днями недели
- ✅ **Экран «Сегодня»** — отметки приёма одним нажатием, прогресс дня
- 🔔 **Напоминания** — Notification API
- 🧪 **Анализы** — 20 показателей с нормами по возрасту и полу, распознавание из файлов
- 🥗 **Рекомендации** — продукты при отклонениях
- 🍽 **Меню на неделю** — генерация с учётом дефицитов семьи
- 🛒 **Список покупок** — автоматически из меню, по категориям

## Технологии

- **Один файл** — `family-health.html` (Vanilla HTML/CSS/JS, ~57 КБ)
- **Без зависимостей** — ноль внешних библиотек, работает офлайн
- **Локальное хранение** — `localStorage`, максимальная приватность
- **PWA** — устанавливается на домашний экран телефона

## Запуск

Просто откройте `family-health.html` в браузере. Для мобильного опыта — откройте на телефоне или используйте DevTools (F12 → режим устройства).

## Публикация через GitHub Pages

1. Откройте **Settings → Pages** репозитория
2. В **Source** выберите `Deploy from a branch`
3. Ветка: `main`, папка: `/ (root)` → **Save**
4. Приложение будет доступно по адресу: `https://<username>.github.io/family-health/family-health.html`

## Дисклеймер

Приложение не является медицинским изделием и не ставит диагнозы. Референсные нормы носят справочный характер; интерпретацию анализов и назначение витаминов выполняет только врач.
